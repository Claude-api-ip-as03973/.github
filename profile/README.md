<p>批量开号时最怕的情况，不是某一条线路不好用，而是十几条线路其实来自同一段地址——表面上每个号都有自己的出口，实际上风控侧看到的是同一个来源。批发场景的决策点因此和买一两条零售完全不同：重点从"这条快不快"变成"这一批散不散"。下面按四组决策项展开，每一项都给判断条件和不满足时的处理办法，最后附一份可以直接照着打勾的验收清单。</p>

<h2>一、先定性：批发买的是地址的分散度</h2>
<p>零售关心单条质量，批发关心整体的分布形状。同一个价格下，十条落在三个自治系统、六个不同网段的线路，实际价值远高于十条挤在一个 /24 里的线路，哪怕后者单条测速更快。</p>
<h3>判断这批地址散不散</h3>
<p>拿到地址清单后先做一次分布统计：涉及几个 ASN、几个不同的 /16 前缀、最密集的 /24 里有几条。经验上，同一批里落在一个 /24 的地址不宜超过两条，ASN 数量至少要有三个，否则一段被标记就整批受影响。</p>
<h3>不满足时的处理</h3>
<p>直接要求拆批供货，或者把需求拆成两次下单、隔开地址段。供货方如果无法说明地址段的来源结构，只能给"保证不重复"这类口头承诺，那就不适合承接批量需求。</p>

<h2>二、第一组决策：出口数量按号算还是按并发算</h2>
<p>这是最容易算错的一项。按并发算看起来省钱，实际会因为任务排队导致某几个号长期抢不到出口。</p>
<h3>什么时候按号配</h3>
<p>账号需要长期保持登录状态、每天都要用同一环境登录的，必须按号配一条固定出口。这种情况下出口数量等于账号数量加百分之十的备用。</p>
<h3>什么时候可以按并发配</h3>
<p>纯批处理、跑完就退出、不要求登录态延续的任务，可以按并发配，出口数取并发峰值的一点二倍。但要注意：这类出口不能和长期养的号混用，两套池子要分开管理。</p>

<h2>三、第二组决策：隔离做到第几层才算够</h2>
<p>"每号独享"这四个字，不同供货方的含义差很远。有的只是不与他人共用同一地址，有的连会话和指纹都隔开。决策时要明确自己需要到第几层。</p>
<h3>四层隔离的取舍</h3>
<p>网络层隔离是基础，指地址不共用；会话层隔离指登录态、cookie 不串；指纹层隔离指浏览器参数各自独立；账号层隔离指资料、支付方式、使用人不交叉。批量开号至少要网络层加指纹层，缺了后者，同段地址的问题解决了，同指纹的问题还在。</p>
<h3>验证隔离是否真的生效</h3>
<p>抽两个号，在同一时段各请求一次回显接口和浏览器特征检测页，比对返回的地址与特征串。地址不同但特征串一致，说明只做了网络层；两项都不同，才算两层都到位。这个动作每月做一次，防止配置被误改。</p>

<h2>四、第三组决策：交付与结算怎么约定</h2>
<p>批量采购的坑多数出现在交付环节，不在技术环节。清单、变更、退换三件事提前写清楚，后面省很多沟通成本。</p>
<h3>交付清单要包含哪些字段</h3>
<p>每条地址至少给：地址、端口或鉴权方式、归属国家与城市、ASN、租期起止、绑定账号编号。缺任何一个字段，后期排查都会卡住。交付后自己复核一遍归属，别直接采信表格。</p>
<h3>退换与结算条款</h3>
<p>明确三件事：多长时间内可以无理由更换、更换是一次性还是按比例、欠费停机的宽限期多久。结算上，批量常见有月付、季付和按量三种，包月单价通常比按量低三到五成，但要先确认淡季能不能暂停。具体价格以各家报价为准，仅供参考。</p>

<h2>五、验收清单：照着打勾就行</h2>
<p>把前面四组决策落成一张表，交付当天逐项过一遍，全部打勾再签收。清单的价值在于避免"当时看着都对，事后说不清"。</p>
<h3>技术项</h3>
<p>地址数量与订单一致；ASN 数量不少于三个；同一 /24 内不超过两条；归属地与需求地区一致；鉴权方式可用；抽检五条做反向解析，无云服务字样。</p>
<h3>流程项</h3>
<p>交付表格字段齐全；绑定账号编号已登记；替换流程与联系人已确认；计费口径与结算周期已书面确认；试用期时长与是否计费已明确。</p>

<h2>常见问答</h2>
<h3>批量买是不是一定比单条便宜？</h3>
<p>答：通常便宜，但不是必然。批量价格的折扣往往和锁定期绑定，锁一年换来的折扣，可能在需求变化时变成浪费。先把用量估算清楚，再决定锁多长，别为了折扣把灵活性卖掉。</p>
<h3>几十个号必须几十条专线吗？</h3>
<p>答：不一定，取决于隔离开到第几层。如果一台机器跑多个独立浏览器配置，每个号固定一条出口，出口数与号数一致但机器可以共用。需要独立设备的情况通常是任务并行度高或者需要物理隔离。</p>
<h3>供货方说"绝不重复"能信吗？</h3>
<p>答：可以作为参考，但不能作为验收依据。交付后自己做一次分布统计，用实际数据判断。承诺无法验证时，把它写进合同条款里，比反复追问有效。</p>
<h3>淡季能不能停掉一部分？</h3>
<p>答：看计费方式。按量计费天然可以停；包月要问清是否支持按比例暂停、暂停期间地址是否保留。地址保留是关键，停了再开换了地址，等于重新做一遍环境验证。</p>
